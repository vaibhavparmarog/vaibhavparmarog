### 🚀 Featured Projects

#### 📄 [ResearchOS](https://github.com/vaibhavparmarog/ResearchOS) — [Live ↗](https://researchos.duckdns.org)
Upload any PDF and get an AI analysis where **every page reference, quote and number is verified against the document**.
- Layout-aware extraction (two-column papers, OCR fallback with Tesseract) → page-aware chunking → map-reduce LLM pipeline
- Multi-provider LLM client (Groq, OpenRouter, NVIDIA, OpenAI, Anthropic) with rate-limit failover, load balancing and request hedging
- Privacy by design: read-only container, uploads in RAM only, reports purged after delivery
- Deployed on **AWS EC2** with Docker, nginx and Let's Encrypt; pytest suite with a deterministic LLM test double

`Python` `FastAPI` `LLMs` `OCR` `Docker` `AWS EC2` `nginx`

#### 🩺 [Vyana · व्यान](https://github.com/piyushgargog/vyana) — AZINHACK '26 (team of 4)
A one-stop AI healthcare app for web and mobile: prescriptions and dose reminders, live medicine price comparison across pharmacies, hospital token booking, NMC-verified doctors, lab-report summaries and an emergency mode.
- AI web agents (TinyFish) fetch live data from pharmacies, labs and the NMC register
- AI health assistant in English, Hindi and Hinglish
- Monorepo with web + mobile apps, shared package and Supabase backend

`TypeScript` `Supabase` `Turborepo` `AI Agents`

#### 🧠 Word2Vec Research Reproduction — GDG-USAR AIML task
Skip-Gram with Negative Sampling implemented **from scratch in PyTorch** and compared against a PPMI+SVD baseline, with experiments on context window size.

`PyTorch` `NLP` `Embeddings` `Research`
